## Open source

Four international AI development competitions in 2026, with working software, source,
documentation and a demo video submitted to each. The three below are public. The fourth,
IntakeArc, is a live product and its source stays private.

**[bastion](https://github.com/kgotsomsiza/bastion)** · AMD Developer Hackathon: ACT II
An accuracy-first, token-efficient general-purpose agent. Classifies each task, routes it to
the cheapest model that can do it well, answers the simplest tasks without a model call at
all, and logs every routing decision. Shipped as a Docker container across eight task
categories. *Python.*

**[AutoReview-Crew](https://github.com/kgotsomsiza/AutoReview-Crew)** · Band of Agents Hackathon
Four agents review a code change together, **recruit a testing specialist mid-run** when
coverage is missing, and escalate risky changes to a human before approval. *Python, MIT.*
Paired with **[autoreview-demo](https://github.com/kgotsomsiza/autoreview-demo)**, a
deliberately buggy PR used as the review target.

**[quotepilot-qwen-hackathon](https://github.com/kgotsomsiza/quotepilot-qwen-hackathon)** · Qwen Cloud Global AI Hackathon (Alibaba Cloud)
Turns a messy customer enquiry into structured intake, a cautious priced quote draft from
the business's own price book, and a customer reply, held for approval or auto-sent once
risk and readiness checks pass. *JavaScript.*
